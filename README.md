# Notebook

Como parte de las practicas independientes de programación y en un esfuerzo para mejorar mis habilidades en el desarrollo de software, se creo este proyecto, se trata de una libreta virtual hecha con PHP.

Este proyecto fue realizado durante mi primer año de aprendizaje de PHP, por lo que que esta hecha unicamente con con **PHP**, **HTML5**, **CSS3** y **JavaScript**, no se realizo la instalacion de ningun framework para el desarrollo de este proyecto, unicamente se hizo uso de librerias de apoyo, por lo que este proyecto fue complicado,como estudiante fue un orgullo completarlo con ayuda de montones de cursos y otros recursos encontrados en internet, libros y por supuesto con ayuda de profesores.

## Proyecto
El objetivo de este proyecto es crear un sitio web el cual permita la creacion, edicion y monitoreo de cuadernos de notas para las diferentes materias escolares.

Cada cuaderno permite tomar, editar y eliminar apuntes, ademas de clasificar por fecha, materia e incluso agregar imagenes como parte de los apuntes.

El proyecto se finalizo al tener un software basico, pero estable, sin embargo esta abierto a montones de mejoras.
